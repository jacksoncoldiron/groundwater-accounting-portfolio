# Start Here

This folder contains the handoff materials for building the Groundwater Accounting portfolio website with Claude Code.

## Files

- `CLAUDE.md` — persistent project instructions. Put this at the root of the Claude Code project/repository.
- `STARTER_PROMPT.md` — paste this as the first substantive prompt to Claude Code.
- `ARCGIS_MAP_CHECKLIST.md` — map specifications for the ArcGIS work you will create separately.
- `EXPANSION_AND_EVIDENCE_STREAMS.md` — quick guide for adding Colusa, Yolo, future basins, and new evidence streams such as board meetings.
- `Groundwater_Accounting_Portfolio_Project_Brief.docx` — human-readable reference version of the same strategy/specification.

## Suggested project setup

Create a project folder containing:

```text
CLAUDE.md
STARTER_PROMPT.md
source_materials/
  Phase2_CrossBasin_Synthesis.docx
  Phase2_Findings_OutlineClassified.xlsx
  Literature_Review_DesktopAnalysis_Results.xlsx
  449 Final Presentation.pdf
```

Add the ArcGIS embeds and authorized illustrations later. Claude Code should use placeholders until they are ready.

## Terminology

The earlier discussion used the term **MVP**, which means “minimum viable product.” In these instructions it has been replaced with **core launch version**: the first complete version that is polished enough to publish, before optional animations and extra features are added.


## Known near-term expansion

The initial analyzed dataset contains Merced, East Turlock, and Salinas Valley. **Colusa and Yolo are known near-term additions.** Build the website skeleton now; do not wait for those analyses.

The architecture should also be ready for a potential future **GSA board-meeting evidence stream**, likely sourced through Waterone.ai. This source is not yet defined and must not be represented publicly as analyzed until real meeting evidence has been added and verified.
